# CICU Waveform Lab

Bedside monitor waveform simulator for pediatric cardiac ICU providers: ECG, arterial line, CVP, SpO₂/pleth and EtCO₂. Three modes:

- **Teach** (`teach.html`): instructor-led. 17 scenarios, live physiology controls, teaching points, Wiggers diagram
- **Learn** (`learn.html`): nine self-paced modules with a Wiggers-diagram walkthrough and practice questions
- **Knowledge Assessment** (`assess.html`): 23 case-based multiple-choice questions with explanations (self-check, no pass mark)

Edit `src/app.html`, then run `./build.sh` to regenerate the three pages. Progress is saved in the viewer's browser only.

Independent approximation of a Philips IntelliVue–style bedside monitor for education only. Not a Philips product or a medical device.
